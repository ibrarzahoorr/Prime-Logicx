# Prime Logicx

Website for Prime Logicx — web & app development (including Shopify), AI automation, and digital marketing/SEO. Static HTML/CSS/JS, no build step.

## Before going live

1. Replace every `https://YOUR-DOMAIN-HERE.com/` placeholder in `index.html`, `robots.txt`, `sitemap.xml`, and `llms.txt` with the real domain (or GitHub Pages URL) once it's decided.
2. Push this folder to a new GitHub repository, then enable GitHub Pages (or point your custom domain at it).
3. Verify the site in Google Search Console and Bing Webmaster Tools, and submit `sitemap.xml`.

## Structure

- `index.html` — full one-page site (hero, services, why-us, process, contact)
- `robots.txt`, `sitemap.xml`, `llms.txt` — SEO/crawler files
